# Kali Linux Learning & Setup Guide

## Timeline
1. Complete final exams
2. Set up Kali Linux environment
3. Begin with basic tools and progress to advanced techniques
4. Practice on legal platforms and labs

## Post-Exam Goals
- [ ] Install and configure Kali Linux after final exams
- [ ] Learn about web penetration testing tools
  - [ ] Focus on website cloning techniques
  - [ ] Understand web application security testing

## Hardware Requirements
- [ ] Purchase external hard drive for data storage
  - Minimum 1TB recommended
  - Consider SSD for better performance
- [ ] Evaluate current laptop specifications
  - Check if upgrade is feasible
  - If budget allows, consider purchasing a new laptop with:
    - Minimum 8GB RAM (16GB recommended)
    - Intel i5/i7 or AMD Ryzen 5/7 processor
    - Dedicated GPU (optional but beneficial for certain tools)

## Learning Resources
- [ ] Official Kali Linux Documentation
- [ ] Web Application Hacking courses
- [ ] Practice on legal platforms like:
  - Hack The Box
  - TryHackMe
  - VulnHub

## Tool Exploration
### Web Tools Focus
1. **Website Cloning**
   - `HTTrack`
   - `wget`
   - `Social Engineering Toolkit (SET)`

2. **Web Application Testing**
   - Burp Suite
   - OWASP ZAP
   - SQLmap

## Budget Considerations
- External HDD: $50-$150
- New laptop (if needed): $800-$1500
- Online courses/certifications: $0-$500

## Notes
- Always ensure ethical hacking practices
- Obtain proper authorization before testing any systems
- Document all learning progress and findings
